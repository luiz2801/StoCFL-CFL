# fedscale

Cópia embutida do FedScale, plataforma de implantação e avaliação de aprendizado federado. Está aqui como código de terceiros, e nenhum script do StoCFL a importa.

## Conteúdo

| Caminho | Descrição |
|---|---|
| `__init__.py` | Vazio, só torna `fedscale` um pacote. |
| `core/` | Runtime do FedScale: agregador, clientes, otimizadores e utilitários. Veja [core/README.md](core/README.md), que é o README original do FedScale. |

## Uso

Não use este código no StoCFL. Para trabalhar com FedScale, use o repositório original. Esta cópia foi mantida para referência e não é parte do algoritmo. Veja a seção 4.13 do [guia](../../../docs/guia.md).
